Informations saisies

Dans cette version statique, les informations saisies dans le formulaire sont utilisées par JavaScript dans votre navigateur pour afficher le CV. Le site ne contient pas de serveur ni de base de données pour recevoir ces informations. Si vous utilisez un ordinateur partagé, fermez l’onglet après utilisation.

Aucune annonce n’est active dans cette version. Si des services publicitaires ou des outils de mesure sont ajoutés ultérieurement, mettez à jour cette politique pour expliquer leurs cookies, leurs données collectées et les choix disponibles aux visiteurs, conformément aux règles applicables.

Ce texte est un modèle de départ, pas un avis juridique. Adaptez-le à vos pratiques réelles et aux obligations applicables dans votre pays.
