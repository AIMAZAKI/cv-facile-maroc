FAQ

Questions fréquentes

Est-ce vraiment gratuit ?

Oui. Cet outil de base fonctionne gratuitement dans votre navigateur.

Mes informations sont-elles envoyées sur internet ?

Non, le code de cette version construit l’aperçu sur votre appareil. Évitez toutefois d’utiliser un appareil public si vous y saisissez des données personnelles.

Comment le site gagne-t-il de l’argent ?

Cette version n’affiche pas de publicité réelle. Après publication, vous pouvez demander l’approbation d’un réseau publicitaire comme Google AdSense. L’acceptation n’est pas garantie et dépend notamment du contenu, de la qualité du site et des règles du réseau.
