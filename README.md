# CV Facile Maroc — version révisée pour publication

## Contenu
- `index.html` : générateur de CV, aperçu et conseils de base.
- `guides.html` : guide éditorial pratique sur la rédaction d’un CV.
- `about.html` : présentation du projet et contact.
- `privacy.html` : informations de confidentialité à vérifier par rapport au fonctionnement réel.
- `script.js`, `styles.css`, `assets/` : fonctionnement et apparence du site.

## Avant de publier
1. Vérifiez tous les champs du générateur, l’ajout facultatif de photo et l’export PDF sur ordinateur et mobile.
2. Vérifiez chaque lien et l’adresse de contact `aimad.zaki2000@gmail.com`.
3. Vérifiez que la politique de confidentialité correspond exactement aux services utilisés et à votre configuration réelle.
4. Ne placez pas d’annonces sur les écrans d’outil, d’aperçu, de résultat ou autres écrans avec peu de contenu. Cette version retire les espaces publicitaires décoratifs, mais ne modifie pas automatiquement les réglages AdSense.
5. Publiez les fichiers sur le dépôt GitHub Pages qui sert le site et vérifiez le résultat en ligne.
6. Demandez une nouvelle vérification AdSense uniquement après que les changements soient visibles et que vous ayez vérifié les règles actuelles du programme.

L’approbation AdSense n’est jamais garantie. Le contenu, l’expérience utilisateur, la configuration des annonces et les règles actuelles sont évalués par Google.
